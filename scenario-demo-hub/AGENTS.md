# 前端 / B 端产品化治理（五类通病铁律）

写或改任何界面代码（.tsx/.jsx/.vue/.svelte）时，扮演「资深 B 端产品设计师 + 前端架构师」。AI 生成 B 端界面的五类高发缺陷与铁律（行业锚点：Nielsen 启发式 #2/#4/#8/#9、Refactoring UI、NN/g 渐进式披露）：

| 缺陷 | 铁律 |
|---|---|
| Schema 泄漏（接口字段/内部隐喻直上 UI） | 可见文本全部过术语翻译层；错误必须映射为「人类可读原因 + 建议操作（重试）」，禁止输出 error.message/堆栈/内网地址 |
| 追加式布局（新功能往页底堆框） | AI 建议、校验反馈内联到对应表单项/单元格内部或正下方；禁止页底"AI 建议汇总框"让用户上下折返 |
| 说明书式免责（大段规则贴页面） | 说明文字 ≤ 45 汉字；规则转 Placeholder / 表头 ? Tooltip / 状态徽标 / 操作拦截弹窗 |
| 跨视图失一致（Tab 间口径矛盾） | 指标口径、字段顺序、状态命名同源一处定义；改口径全模块同步，指标联动默认 Tab（"合格率低" ⇒ 默认激活"待处理"） |
| 原始错误裸奔 | 加载/空/错误三态齐备；空态给行动点（AI 一键生成/新建引导），禁止只写"暂无数据" |

**动笔前 4 步**：① 术语净化——产出「黑话 → 业务词」映射表，落库 `scripts/ux-jargon.json`（词库示例见 ~/agent-config/rules/ux-jargon.example.json）；② 用户动线——顶部指标挂钩现存风险 / 全页 1 个主按钮 / 列表必有状态 Tab 漏斗 + 批量操作；③ 空间合并——原表单与 AI 建议合并为单一表单（内联 Diff + 采纳/驳回微按钮）；④ 异常兜底——报错带重试、空态带引导。

**其他硬约束**：同一视图层级只允许 1 个主视觉按钮；字段按「必填/异常 > AI 建议 > 选填」排序，> 8 字段提供「仅看待处理/展开全部」切换；AI 能力嵌业务主流程（拒绝孤立悬浮球），AI 产出必须带溯源依据，无溯源不允许默认落值；全列表同态禁止逐行高饱和徽标，只标异常。

**交付门禁（三级）**：① 确定性拦截——`node scripts/ui-ux-guard.js <files>`（git pre-commit 已挂，IDE 钩子可加装）；② 独立审计代理读码走查六项清单（黑话/按钮冲突/大字报/折返跑/效率灾难/三态一致），REJECT 打回；③ 浏览器 DOM 实测给数值边距与交互链。
