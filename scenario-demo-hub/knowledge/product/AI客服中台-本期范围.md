# AI 客服中台 · 本期范围与产品边界

> 2026-10-13 按合同版 SOW 3.2.6 / 3.3.1 / 3.3.2 / 7.2 复核。演示按总分只画在线 AI 客服。人工坐席与客服六维报表在合同里，本期不进主链。

## 总分怎么读

| 层 | 页面 | 本期写什么 |
|---|---|---|
| 商城总 | `overall-flow` 的 07 售后客服 | 只点在线有人答、答不了留痕 |
| 客服总 | `ai-cs-overview` | 总流程：在线接入 → 意图 → 同一轮（FAQ 原文 / 商品知识 / 订单查询）→ 留痕 → 知识回流。斜纹两条：人工坐席、六维报表 |
| 工作流 | `ai-service` | 从总图「应答主链」点进。开放问题、商品知识、订单真值，整页从接入走到拒答 |
| 技术 | `service-faq` | 从总图「FAQ 技术」或应答主链「FAQ标准答案」点进。只说明第 03 步怎么取原文，不重画接入、商品知识和订单 |
| 合同全景 | `contract-blueprint` 的智能客服中台 | 合同编号可以列全，面板必须拆开「本期画进主链」和「后期再接」 |
| 能力地图 | `capability-map` | 规划视图。人工接待、AICS-029 不标成已交付 |

商品治理、集采合规里的「转人工」是业务例外（运营判卷），不是客服坐席。那些句子留在各自页面，不叫客服转人工。履约对账不在 AI 全景里。

## 本期画进主链

入口只有在线：站内对话、网页挂件（商品详情、订单详情可嵌入口）。

主链：在线接入 → 意图识别（政策或固定问法 / 商品 / 订单）→ 三路并列，各自结束 → 发出前核对敏感词 → 人确认后的句子，在线回答一起用。点「应答主链」看这三路的步骤，点「FAQ 技术」只看第一路怎么取原文。订单查询先在已登录的网页挂件上开放，并核对订单归属。

演示文案不写命中比例、正确率和知识生效时间。合同里的验收要求留在合同和 PRD，验收时再对照。

合同条目里，本期认这些：

| 编号 | 合同功能 | 本期怎么用 |
|---|---|---|
| AICS-001 | 虚拟客服账号、分场景形象 | 在线账号 |
| AICS-003 / 004 | 页面嵌入、客户会话页 | 客户只看到这一侧 |
| AICS-006 / 007 | 引用商品与订单、文本图片附件 | 客户侧消息 |
| AICS-008 / 009 | 会话留痕回顾、核心指标 | 只记问了什么、答上没有、有没有拒答、采购觉得有没有用。这是会话记录，不是经营报表 |
| AICS-016 | 识别初始意图，判断是否智能接待 | 「不该智能接待」的动作见下方边界，本期不转人 |
| AICS-018 / 019 | 商品与交付问询、订单问询 | 商品走知识库；订单查接口，不生成 |
| AICS-020–023 | FAQ 强制标准回答、商品库、分库、引用规则 | FAQ 与 RAG 的事实源 |
| AICS-024 / 025 | 模型可切换、效果评价收集 | 评价收集可以有；不据此做六维报表 |
| AICS-027 / 028 | 敏感词、在线参数 | 在线会话的拦截与阈值。不是坐席质检 |

答不了的固定话术拒答，问句留下，交给知识运营补条目。不硬答。

知识运营改 FAQ、抽查拒答，是运营岗位，不是人工客服坐席。

## 边界一：人工客服（合同有，后期再接）

合同 3.2.6 的「人工接待」和 3.3.1 里的「人工接管」都在实施范围里。本期演示不接通。

| 编号 | 合同原文在说什么 | 本期 |
|---|---|---|
| AICS-002 | 智能体接待与人工接待排班 | 只保留虚拟账号；排班后期 |
| AICS-005 | 接待员回复端口、多会话切换 | 坐席工作台，后期 |
| AICS-010–015 | 排队、留言、双向消息、人工会话风险提示、转接、释放名额 | 整段后期 |
| AICS-017 | 意图转变后智能转接人工客服 | 识别保留，转接后期 |
| AICS-026 | 人工接待账号 | 后期 |

边界情况（演示和验收都按这张表，不要临时改口）：

1. 用户说「转人工」、投诉、高风险词、库外或低置信：本期识别为「应转人」，动作是固定拒答 + 会话留痕。不排队、不派坐席。
2. 合同里的转接验收等坐席接入后再做。本期识别「应转人」，动作是拒答留痕。
3. 合同里的回答质量要求留在 SOW，不写进演示文案。分母是在线 AI 答过的问题，不是坐席解决率。
4. 夜间无人坐席：本期仍由在线 AI 值守；答不了的留痕。AICS-010–015 人工接待整段后期再接。
5. 治理、合规页面里的「转人工」指业务人员处理例外，不接入这套客服队列。

## 边界二：报表（三套不要画成一套）

SOW 3.3.2：报表以业务闭环、管理监控和验收所必需的、双方确认过的清单为准。清单外的新报表或复杂可视化按变更处理。演示页不自造客服经营大屏。

| 套 | 合同位置 | 本期 |
|---|---|---|
| 在线会话统计 | AICS-008 留痕回顾、AICS-009 核心指标、AICS-025 评价收集 | 做。只回看：问了什么、答上没有、有没有拒答、采购觉得有没有用、有没有被敏感词拦住 |
| 客服运营报表 | AICS-029：呼叫量、接通率、坐席绩效、满意度运营看板、服务质量、业务趋势与预测 | 不做。接通率和坐席绩效没有坐席就没有分母。趋势预测也不做 |
| 商城报表中心 | OP-117–121：经营概况、目标、履约、浏览、订单统计 | 不属于客服中台。不画进客服页 |

「看分流准不准」若出现，只指向会话统计里的计数，不指向 AICS-029。

## 本期不做（汇总）

- 人工客服：排队、坐席工作台、坐席辅助、转人工、留言、转接
- AICS-029 六维报表，以及任何未确认的客服经营大屏
