# 页面布局与展示流程设计（任务E 定稿）

> 场景：评审/汇报导向的场景演示平台。读者 = 业务+技术评审，目标是"不走丢、看得懂、随时深挖"。
> 适用范围：HubHome 与 ScenarioPage 的布局交互改版；后续新页面须沿用本文约定。

## 一、设计原则（乔布斯产品视角的落地翻译）

1. **先讲为什么，再讲怎么做，最后讲带来什么**——三段叙事章节：
   01 业务场景与用户痛点 → 02 场景融合使用流程 → 03 使用 AI 前后对比。
2. **一屏一个主角**：Hero 只传达定位与规模；详情只在被召唤时出现（抽屉），不抢占流程图上下文。
3. **颜色即导航**：平台识别色建立视觉记忆（全景墨 #27313d / 商品橙 #e24a10 / 搜索蓝 #2b6cb8 / 客服绿 #2f9e6e），比文字标签更快。
4. **不出戏**：空状态不暴露开发提示（"往 scenarios/ 放 JSON"），收敛为业务语言"场景筹备中"。

## 二、核心技术约束与解法

### 1. fixed/sticky 与 transform 坐标系冲突（最高优先级）
- `scale-inner` 有 `transform: scale()` → 其内部 `position:fixed` 元素会相对 inner 定位并被缩放（CSS 规范：transform 创建新的包含块）。
- **约定：所有 fixed 元素（topbar/drawer/modal）一律渲染在 `scale-outer` 层**（同 RefModal 先例），始终原生尺寸可读。
- 顶栏让位用 `.scale-outer { margin-top: 52px }`——margin 不计入 `useScale` 的 `outer.style.height = inner.scrollHeight * s`，不干扰缩放高度计算；若改用 inner padding 则会污染。

### 2. 缩放画布下的锚点滚动
- `getBoundingClientRect()` 返回**物理像素**，`window.scrollTo({ top: el.getBoundingClientRect().top + window.scrollY - OFFSET })` 天然正确，无需除以 scale 换算。

### 3. scrollspy 触底规则（易漏）
- IntersectionObserver `rootMargin: "-30% 0px -60% 0px"` 让章节进入视口中段即高亮。
- **坑**：末段物理高度 < 视口高时，滚动被页面底部钳制，末段永远到不了观察带，点击末段导航高亮不切换。
- **解法**：nearBottom 判定（`innerHeight + scrollY >= scrollHeight - 8`）时强制激活末段——IO 回调内与 scroll 监听双保险（IO 回调可能最后到达，单靠 scroll 监听会被 IO 覆盖）。

### 4. 右抽屉详情模式
- 点节点 = 高亮 + 抽屉滑出（560px / max-width 94vw，`cubic-bezier(0.2,0.8,0.3,1)` 0.24s）；流程图保持可见，反馈不脱离上下文。
- 复用 DetailPanel，靠 **CSS 去壳**（drawer 内 `.panel` 去边框/阴影/内边距，`.p-grid/.svwrap` 强制单列），不改组件代码。
- ESC / 遮罩关闭；关闭保留节点高亮（`selectedId` 与 `drawerOpen` 两个状态分离）。

## 三、组件契约

- `CompareSection` 接收 `no: string`，章节标题统一 `sec-h`（序号胶囊 em + 标题 + small 副标题）。
- `FlowCanvas.onSelect: (id: string) => void` 与页面侧 `selectNode(id: string | null)` 兼容（string 是子类型），点空白处 FlowCanvas 内部不调 onSelect，无需改 FlowCanvas。

## 四、验证方法论（agent-browser 目检）

1. cache-bust 必须放 **hash 之前**：`/?v=N#/s/xxx`（放 hash 内被当路由参数，静默落回首页）。
2. eval 断言结构存在性（`hasTopbar`/`secCount`）比截图更快识破"落回首页"类问题；场景 id 笔误也会静默落首页。
3. 截图全页用 `-f/--full`；PNG 读取偶发上传失败改 `--screenshot-format jpeg`。
4. 浏览器会话可能丢失（落 about:blank），每轮先 `eval location.href` 确认在场。
5. scrollspy/跳转类验证：点击后 sleep ≥ 1.8s（smooth scroll 时长），再读 `.on` 类与 `getBoundingClientRect().top`。
