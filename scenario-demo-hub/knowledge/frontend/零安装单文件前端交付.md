# 零安装单文件前端交付模式

> 场景：交付给非技术干系人的演示页面，要求"双击即开、零安装、可拷 U 盘/发邮件"。

## 四件套
1. **vite `base: './'`**：产物内资源引用改为相对路径，file:// 下不 404。
2. **vite-plugin-singlefile**：JS/CSS 全部内联进单个 index.html——杜绝"少拷一个文件就白屏"。
3. **hash 路由**：`#/s/<id>`。file:// 协议下 history API 路由不可用，hash 是唯一可靠形态。
4. **import.meta.glob eager 加载数据**：`scenarios/*.json` 构建期打进包，运行时零请求。

## 构建期 fail-loud
校验脚本挂在 `npm run build` 之前（`prebuild`），配置有错直接构建失败——
**让错误停留在作者机器上，绝不带到汇报现场。**

## 宽屏演示自适应（useScale）
- 画布按 1360px 逻辑宽度固定布局（泳道图这类精密排版不适合响应式重排）；
- `transform: scale(clientWidth / 1360)` 整体缩放，双向生效（大屏放大、小屏缩小）；
- scale 后元素占位高度不变，需用 ResizeObserver 把外层容器高度收拢为 `innerHeight × scale`，否则底部留白/截断；
- 实测基线：1920→scale(1.15)、1100→scale(0.7588)，均无横向滚动条。

## 体积参考
React 19 + zod v4 单文件产物约 360KB（gzip 113KB）——离线演示完全可接受。
